
# DRAW MODE (active)

In this run **you draw every picture yourself.** Always return `mode: "custom"` with a complete SVG, or `mode: "none"` when no picture helps. Don't return `library`.

The catalogue above is now your **design vocabulary, not a menu**: it lists the kinds of pictures EduPlay uses and what each must contain. Draw the right kind for the question, in exactly the same look as the reference drawings you were shown (they come from the official EduPlay library). Match:
- **Composition:** items in rows of 5, the first item on the right; groups in rounded soft-colour boxes with a yellow size chip below and a "+" between them; ten frames with a thick ink border; tracks and charts left-to-right.
- **Shapes:** flat icon-like objects with one white highlight; thick ink outlines only on frames, axes and shapes being studied; rounded corners everywhere.
- **Colour:** the subject colour and its soft tint, yellow `#FFC940` for given numbers, ink `#16213E` for structure. The colours used in the reference drawings are allowed.
- **Type:** Rubik 800–900 for numbers, Assistant 700–800 for Hebrew labels, nothing below 12px.
- **Model the process:** draw the situation so the child solves it by counting (cookies dealt next to each child, all the rows, shaded parts).
- **Unknowns:** the dashed blue "?" box. Never write or point to the answer.

In draw mode the limits are wider: viewBox up to 1000×800, and up to 140 text items (number labels on tracks, charts and clocks).
